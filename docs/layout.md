# Layout

| File                 | What it holds                                                                                                                   |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `index.html`         | Page shell: honeycomb view and map view                                                                                         |
| `pipelines.js`       | The tree of groups and pipelines                                                                                                |
| `catalogue.js`       | Every active nf-core pipeline with its description and latest release, generated by `bin/update-catalogue.py`                   |
| `stations.js`        | Every station: what it is, what it takes, what it gives                                                                         |
| `handoffs.js`        | Every handoff between two stations, with its status, the files or params it goes through, a note, and the day it was checked    |
| `maps/<pipeline>.js` | One interchange map: where each station sits (`at`) and the handoffs it draws besides its hub's (`also`) or leaves out (`skip`) |
| `js/registry.js`     | `MAPS` and `registerMap`, which every map file calls                                                                            |
| `js/model.js`        | What a map draws: its stations and handoffs, coloured, without the DOM; and the handoff statuses (`ST`)                         |
| `js/map.js`          | Draws a metro map from a map file                                                                                               |
| `js/app.js`          | Honeycombs, zooming between levels, breadcrumbs, routing (`#<id>`), theme                                                       |
| `bin/check.js`       | Checks the tree, stations, handoffs and maps; run by the Render workflow and by prek                                            |
| `style.css`          | Styles for both views                                                                                                           |
| `docs/images/`       | Logos, generated with `nf-core pipelines create-logo interchange`                                                               |
